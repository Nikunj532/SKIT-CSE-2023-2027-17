\# Adhikar Setu - Database Design



\## Scheme



Each government scheme will contain:



\- scheme\_id

\- name

\- description

\- ministry

\- state

\- category

\- benefits

\- eligibility

\- documents

\- application\_process

\- official\_url



\## Future User Profile



The system may use:



\- age

\- state

\- occupation

\- income\_range

\- gender

\- education

\- category

\- disability\_status

\- other scheme-specific criteria



\## Future Retrieval



Scheme discovery will use:



1\. Structured filtering

2\. Keyword search

3\. Semantic/vector retrieval

4\. Hybrid retrieval

5\. Reranking



\## Important



Only verified government-source information should be presented

as official scheme information.
